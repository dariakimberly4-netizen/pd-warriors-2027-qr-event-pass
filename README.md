# PD Warriors Get Together 2027 — QR Event Pass

Offline-first event pass prototype for Parkinson's Disease Warriors Philippines.

## Features
- Participant registration/search
- Walk-in registration with reserved W numbering
- Registration, Snack, Lunch and Raffle entitlements
- One-claim-only protection
- Local offline storage
- CSV event report export
- Mobile-friendly design

> QR image generation currently uses an online QR image endpoint. Generate/screenshot passes before losing connectivity. A fully bundled offline QR encoder can be added next.
